# Security policy

Current status: community beta. There is no committed security support SLA.

**Do not disclose unpatched vulnerabilities or personal SMS content in public issues.** Use GitHub's private vulnerability reporting if enabled in the repository's **Security → Advisories → Report a vulnerability** settings. If private reporting isn't available, ask a maintainer for a private contact channel without describing exploit details publicly.

Potentially sensitive components include Windows Credential Manager storage, HTTP Basic Auth, local JSON message history, CSV exports, and autostart registry settings.

Never share your private SMSGate URL, usernames, passwords, message caches or Windows credentials when reporting a bug. The application is intended for a private network, not exposure on the public Internet.
